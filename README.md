## About me

I am a developer who likes taking an idea from a rough sketch to a working product. My work usually sits between **frontend experience**, **backend structure**, **data organization**, and the practical decisions that keep a project maintainable.

I care about interfaces that are easy to use, code that is easy to revisit, and documentation that helps people understand what a project is doing. I also enjoy giving personal projects their own character instead of making everything look the same.

## What I work on

| Area | What that means in practice |
|:--|:--|
| Product interfaces | Responsive pages, clear flows, thoughtful layouts, and useful interaction details. |
| Full-stack systems | Frontend and backend pieces that communicate clearly and remain easy to extend. |
| Data and storage | Structured data, SQL schemas, metadata, private repositories, and controlled storage. |
| Project quality | Documentation, consistent Git workflows, readable code, and careful finishing work. |

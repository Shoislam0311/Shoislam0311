## Aniraku

<a href="https://www.aniraku.tech/">Open the web app</a>
&nbsp; · &nbsp;
<a href="https://github.com/Aniraku/Aniraku">Web source</a>
&nbsp; · &nbsp;
<a href="https://github.com/Aniraku/Aniraku-App">Android source</a>
&nbsp; · &nbsp;
<a href="https://aniraku.github.io/Aniraku-App/">Android download site</a>

**Aniraku** is an open-source anime discovery and viewing platform. The web app connects catalog browsing, schedules, recommendations, playback, watch history, ratings, bookmarks, comments, and progress in one place.

The public web project uses `React`, `Vite`, `Artplayer`, `HLS.js`, `AniList`, and `Supabase`. The Android project has its own player, library, history, relationships, provider controls, and Android 9+ distribution path.

[Live site](https://sikder-three.vercel.app/) · [Source](https://github.com/Shoislam0311/Sikder)

## <img src="./assets/ui/icons/hello.svg" width="20" height="20" />&nbsp; hi, i'm showaib

> an open-source developer from bangladesh making web things, api things, and occasionally overthinking a button for three hours.

i like interfaces with a little soul, code that stays readable after the dopamine wears off, and side projects that start as "this would be funny" and somehow become real. my current main-character arc is **[aniraku](https://github.com/Aniraku)** — anime discovery and watching, built with care for web, android, and the api holding it all together.

usually found somewhere between frontend polish, backend systems, deployment rabbit holes, anime, and music that makes the room feel like a different decade.

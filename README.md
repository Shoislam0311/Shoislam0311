### Reference layer

The visual direction is an original interpretation of broad public cues visible in [Nothing's Phone (3) design presentation](https://us.nothing.tech/products/phone-3): modular sections, restrained monochrome surfaces, technical labels, small red accents, and a Glyph-inspired dot rhythm. The repository cards use the user's own public project pages and existing project banners. Badges and icons are served by the open-source [Shields.io](https://github.com/badges/shields) and [Simple Icons](https://github.com/simple-icons/simple-icons) projects; the activity widgets come from [GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats) and [GitHub Readme Activity Graph](https://github.com/Ashutosh00710/github-readme-activity-graph).

## / about me

Hi, I’m **Showaib**, a developer from Bangladesh. Most days I’m somewhere inside a frontend, a Go or Python API, or a side project that was only meant to take one evening.

I’m building [Aniraku](https://www.aniraku.tech/) because I wanted anime discovery and watching to feel simpler. I like fast interfaces, useful defaults, readable code, and tools that stay out of the way. Anime and music usually find their way into the things I make anyway.

## About me

I’m **Showaib Islam**, a developer from Bangladesh who enjoys turning ideas into polished, useful software. My work moves between frontend experiences, backend APIs, databases, deployment, and the small details that make a product feel complete.

I’m most interested in products with a clear purpose: tools people can actually use, interfaces that feel intentional, and systems that remain understandable after the first release. A lot of my work is connected to **Aniraku**, an open-source anime discovery and viewing platform that I build with others.

| Currently building | Learning and improving | Always happy to discuss |
|:---|:---|:---|
| Aniraku web and Android experiences | Product engineering and system design | React, TypeScript, APIs, anime platforms |
| Useful web products and small tools | Backend architecture and deployment | UI polish, Supabase, FastAPI, open source |
| Reliable, readable developer workflows | Better documentation and maintainability | Collaboration and ambitious side projects |

## Aniraku — open-source anime, thoughtfully built

<div align="center">

<a href="https://www.aniraku.tech/"><img src="https://img.shields.io/badge/Live%20web%20app-7C3AED?style=for-the-badge&logo=googlechrome&logoColor=white" alt="Aniraku live web app" /></a>
<a href="https://github.com/Aniraku/Aniraku"><img src="https://img.shields.io/badge/Web%20source-18181B?style=for-the-badge&logo=github&logoColor=white" alt="Aniraku web source" /></a>
<a href="https://github.com/Aniraku/Aniraku-App"><img src="https://img.shields.io/badge/Android%20source-166534?style=for-the-badge&logo=android&logoColor=white" alt="Aniraku Android source" /></a>

</div>

**Aniraku** brings discovery and watching into one focused experience. The platform connects catalog browsing, schedules, recommendations, playback, watch history, ratings, bookmarks, comments, and progress tracking without losing the joy of exploring something new.

The public web project uses `React`, `Vite`, `Artplayer`, `HLS.js`, `AniList`, and `Supabase`. The Android project has its own player, library, history, relationships, provider controls, and Android 9+ distribution path.
